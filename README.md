# sap-loi-69-21-payment-terms
Les entreprises marocaines qui utilisent SAP ont besoin d'un outil qui prépare automatiquement la déclaration des délais de paiement exigée par la loi 69-21 : il doit trouver les factures fournisseurs payées en retard, calculer l'amende et produire l'état à joindre à la déclaration.
